All 3 required attributes are present on this one line:
  httponly  -- JavaScript on the page can't read this cookie
  samesite=lax -- not sent along with most cross-site requests
  secure    -- only ever sent over HTTPS in production
(Full copy: screenshots/set_cookie_header.txt)

--- Logout, then reuse the SAME (now-revoked) cookie against /dashboard ---
$ curl -s -o /dev/null -c cookies.txt -X POST http://127.0.0.1:8675/login -d "username=admin&password=password"
$ curl -s -o /dev/null -w "HTTP %{http_code}\n" -b cookies.txt http://127.0.0.1:8675/dashboard
HTTP 200
$ curl -s -D - -o /dev/null -b cookies.txt http://127.0.0.1:8675/logout
HTTP/1.1 302 Found
location: /login?logged_out=1
set-cookie: session=null; path=/; expires=Thu, 01 Jan 1970 00:00:00 GMT; httponly; samesite=lax; secure
$ curl -s -D - -o /dev/null -b cookies.txt http://127.0.0.1:8675/dashboard
HTTP/1.1 302 Found
location: /login
(PASS -- the exact same cookie that returned 200 a moment earlier is rejected
after logout. Full copy + explanation: screenshots/cookie_reuse_proof.txt)

Note: an earlier attempt at this same test accidentally showed the *first*
curl (immediately after login) already returning 302 instead of 200 --
about 6.5 minutes had passed between logging in and running the test during
normal back-and-forth conversation, which exceeded the default 5-minute
idle timeout on its own. Not a bug -- an unplanned, genuine demonstration
that idle timeout works, in addition to the deliberate test below.

--- Idle timeout test (IDLE_TIMEOUT_SECONDS=3, restarted server for a fast demo) ---
$ IDLE_TIMEOUT_SECONDS=3 python3 main.py
$ curl -s -o /dev/null -c cookies3.txt -X POST http://127.0.0.1:8675/login -d "username=admin&password=password"
$ curl -s -o /dev/null -w "HTTP %{http_code}\n" -b cookies3.txt http://127.0.0.1:8675/dashboard
HTTP 200
$ sleep 5
$ curl -s -D - -o /dev/null -b cookies3.txt http://127.0.0.1:8675/dashboard
HTTP/1.1 302 Found
location: /login?expired=1
set-cookie: session=null; path=/; expires=Thu, 01 Jan 1970 00:00:00 GMT; httponly; samesite=lax; secure
(PASS -- idle session expired on its own after the timeout window and was
rejected; note the redirect target, /login?expired=1, is distinct from
/login?logged_out=1 used by an explicit logout.)
